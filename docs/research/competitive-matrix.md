# Competitive research — initial evidence pass

Date: 2026-11-04. Status: desk research only, not hands-on benchmark. Feature availability, pricing and licenses need direct testing before final decision.

| Platform | Verified strengths | Implication for ProPro | Evidence |
|---|---|---|---|
| GitHub Projects | Table/board/roadmap views, custom fields, charts, issue and PR integration | Avoid competing on Git-centric planning; repositories must remain optional linked resources | https://docs.github.com/en/issues/planning-and-tracking-with-projects |
| Plane | Boards, lists, Gantt, initiatives, AI agents, approvals, API/MCP and GitHub sync | AI task management and agent support are not unique differentiators | https://plane.so/ ; https://docs.plane.so/integrations/github |
| Backstage | Software catalog, ownership, entity relationships, extensible plugins and templates | Strong candidate for software-only extension, less direct fit for a universal nonsoftware-first UX; test rather than assume | https://backstage.io/docs/features/software-catalog/ ; https://backstage.io/docs/overview/technical-overview/ |
| OpenProject | Configurable work packages, relations, permissions, projects, portfolio/workspace API and BIM-oriented API | Strong project-management baseline; compare construction workflows hands-on | https://www.openproject.org/docs/api/ ; https://www.openproject.org/docs/user-guide/work-packages/ |
| Bonsai | Client portal with files, invoices, communication, task collaboration and activity | Freelancer client portals are established; do not position this alone as novel | https://help.hellobonsai.com/en/articles/4409019-how-to-use-the-client-portal |

## Preliminary findings
- No validated claim that competitors cannot support mixed project types. Test multi-capability scenarios before claiming a gap.
- ProPro hypothesis: cross-discipline project composition + typed evidence-backed relationships + approachable onboarding may be useful together.
- Plane and OpenProject are high-priority hands-on comparators for general project management; Backstage for software catalog reuse; Bonsai for freelancer workflow.

## Remaining evidence gaps
Construction-specific platforms (e.g. Buildertrend), research platforms (e.g. OSF), pricing/licensing and exports, offline capability, permissions, workflow performance and mobile UX. Record actual task runs, costs and restrictions in follow-up passes.
