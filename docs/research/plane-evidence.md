# Plane candidate assessment — evidence pass 2

Date: 2026-11-04. Status: documentation review only, not hands-on benchmark.

## Verified capabilities
- Workspace initiatives span projects and individual work items; feature documented as Pro: https://docs.plane.so/core-concepts/projects/initiatives
- Project features include modules, cycles, pages, milestones, time tracking, releases and custom work-item types: https://docs.plane.so/projects/project-settings
- Workspace features include customer records, relations, project states and agents; some settings are irreversible: https://docs.plane.so/workspaces/workspace-features
- Workspace exports can be CSV, Excel or JSON; exports reflect projects user can access, not necessarily entire workspace: https://docs.plane.so/workspaces/workspace-settings
- GitHub integration is Pro, supports bidirectional issue/comment sync and PR-driven state updates: https://docs.plane.so/integrations/github

## Assessment
Plane already offers cross-project initiatives, modular feature toggles, customer records, workflow automation and export. ProPro cannot credibly claim those features are absent from existing products. Plane is a serious adopt/extend candidate, but plan/tier constraints and irreversible configuration choices matter.

## Unverified questions
Can a single project combine construction measurements/material estimates, research provenance and freelance client review without fragile custom fields? Is full-fidelity export/import possible including attachments, relations and permissions? What is the exact license and total self-hosted operating cost for the necessary features? How intuitive is the first-time experience on mobile?

## Required test
Use the same three project fixtures and export/accessibility rubric as OpenProject. Test without paid features first, then document what needs a paid tier. No claim of successful trial until executed.
